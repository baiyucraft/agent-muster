## 2. 系统路径与状态来源

~~~mermaid
flowchart TD
    Source["事件来源<br/>HTTP、Webhook、cron、人工补跑"]
    Http["中台 HTTP 层<br/>认证、结构校验、长轮询"]
    Rules["规则与时钟<br/>选 Agent、定目录、并发约束"]
    Decide["状态决策<br/>事件、轮次、卡片、复查"]
    Db["SQLite<br/>事实日志、查询投影、到期索引"]
    Worker["设备 Worker<br/>认领、保存运行记录、监督进程"]
    Launch["Agent 启动插件<br/>命令参数、会话、输出"]
    Cli["设备已有 CLI<br/>执行任务，返回最后消息和可用量"]
    Receipt["回执与结果<br/>本地先落盘，允许重传"]
    View["CLI 总览、状态快照、事实流"]
    Card["飞书、Webhook、桌面、单卡页面"]
    Answer["用户决定<br/>保存答案，唤醒原事项"]
    Source --> Http --> Rules --> Decide --> Db
    Db --> Worker --> Launch --> Cli --> Receipt --> Http
    Db --> View
    Db --> Card --> Answer --> Http
~~~

中台把外部时间和环境注入决策函数。一次事实追加、投影更新、到期索引写入使用同一 SQLite 事务。数据库配置为 WAL 与 FULL。业务视图带序号与格式指纹。正常重启使用现有投影，指纹变化触发从事实重建。进程运行证据和未送达回执另在 Worker 本地持久化。PR、外部 CI 与部署状态回读 GitHub 或健康端点。 [事务](https://github.com/KKKKhazix/agent-autoloop/blob/d1ec2d8e48de62b2a49bd8dc5985c03482c753ce/kernel/store.ts#L1-L49) · [运行时](https://github.com/KKKKhazix/agent-autoloop/blob/d1ec2d8e48de62b2a49bd8dc5985c03482c753ce/host/runtime.ts#L27-L136) · [状态权威说明](https://github.com/KKKKhazix/agent-autoloop/blob/d1ec2d8e48de62b2a49bd8dc5985c03482c753ce/docs/state-machines.md#L19-L61)

## 8. 首版取舍及验收

| 取舍 | 可带入 Muster 的具体设计 | 建议验收 |
