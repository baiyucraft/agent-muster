# Agent Muster 项目 Wiki

Agent Muster 让你在一条 Web 主对话里，把工作交给不同设备、不同项目里已有的 Agents。日常进度在看板查看，需要你决定时通过 Web 或 IM 请示，办完后回到原对话汇报。

**项目阶段：v0.1 工程骨架。** 已建立 Go 中心服务、设备 daemon、本机命令、中心 dsh 插件和 React 工作台的入口。[本地构建与运行](./01-快速上手/INDEX.md#本地构建与运行)列出当前可验证的能力。PostgreSQL、设备 SQLite 和单设备任务闭环的实施目标见[首版设计稿](../.docs/agent-muster-v0.1.md)。
