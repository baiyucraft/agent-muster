# 开发指南

[返回 Wiki 总索引](../INDEX.md)

本节收录 Agent Muster 的开发约定。产品行为和首版验收场景见[首版设计稿](../../.docs/agent-muster-v0.1.md)。

## 开发原则

- 先查仓库已有实现与依赖，沿用满足要求的逻辑、组件和接口。遇到已有成熟解法的问题，建议阅读对应项目的源代码和测试，核对适用条件与失败行为。直接复用代码时遵循上游许可证并保留必要的署名。
- 优先改进现有方案，用简单、清晰、可维护的实现满足当前需求。等到有实际用例再引入新的抽象、配置和扩展点。
- 把用户体验作为设计和实现取舍的首要依据。沿实际操作流程判断用户能否找到入口、完成工作并理解结果。前端的视觉质感、动效和验收要求见[前端组件与复用](03-前端组件与复用.md)。
