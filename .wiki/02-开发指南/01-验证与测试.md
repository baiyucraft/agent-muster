# 验证与测试

[返回开发指南](INDEX.md)

## 选择验证范围

- 先明确变更影响的入口和调用方，从最接近改动的现有检查开始。涉及跨模块契约、持久化、历史数据或用户操作时，补充覆盖相关边界的验证。
- 单元层适合验证状态转换、参数解析和失败分支。集成层用于验证数据库事务、连接与进程的实际行为。跨设备、CLI 原生续接和 IM 能力通过真实部署链路验收。
- 对故障修复，优先使用能稳定复现原问题的最小用例。有必要时把缺失场景补进相应的测试层。
- 记录验证入口、命令或操作步骤、环境与版本、结果，以及本次受环境约束而无法验证的场景。Git 候选验证应记录提交 SHA，失败时保留可复查的日志位置。

## 工程检查入口

| 命令 | 验证内容 |
| --- | --- |
| `pnpm check` | 全项目检查。运行 ESLint、三个工作区的 TypeScript 类型检查、Node 工具测试、dsh 插件编译与测试、Go 检查和文档检查。 |
| `pnpm run check:go` | 只读检查 Go 源码格式，分别在根模块和 `cmd/muster-daemon` 运行 `go vet` 与 `go test`。Windows 桌面模块使用 `production` 构建标签。 |
| `pnpm run lint` | Web、Wails UI、dsh 插件、相关配置和工具的 JS／TS 检查。 |
| `pnpm run docs:check` | Wiki 元数据、目录与索引，以及 Wiki 和 Skill 的本地链接与 Markdown 锚点。 |
| `pnpm run test:tooling` | 文档检查、ESLint 和 Go 注释规则的行为测试。 |
| `pnpm run lint:go-docs --base HEAD -- <路径>` | 对照指定 Git 基线，核对 Go 导出函数、方法和类型的新增或变更注释。默认读取工作区，可用 `--staged` 或 `--ref <版本>` 指定候选。 |

在仓库根目录使用 Git、Go 和 Node，先运行 `pnpm install --frozen-lockfile` 安装工作区依赖，再执行 `pnpm check`。Windows 还需要 `wails3`，Go 检查会生成桌面程序嵌入的图标，并从当前源码构建 `frontend/dist`。这两个输出属于 Git 忽略的本地构建产物。Go 静态分析和测试使用当前平台的构建条件，其他平台检查桌面模块的占位入口。

Go 注释规则通过 `pnpm run lint:go-docs` 按 Git 候选单独检查。PostgreSQL 集成测试需要 `MUSTER_TEST_DATABASE_URL` 指向临时测试库。Windows 更新往返测试使用 `MUSTER_TEST_WINDOWS_UPDATE=1`。两台实体设备协作按真实链路验收。

在部分暂存或有其他相关修改的工作区验证时，先核对工具读取的内容与候选一致。记录验证对应的 tree 或 SHA、命令、结果和测试跳过原因。Wails 完整构建可能整理模块及重新生成资源，按需在隔离候选中运行。

## 产品实现的关键验收

下表提炼跨组件回归测试，完整场景见[首版设计稿](../../.docs/agent-muster-v0.1.md)第 10.2 节。

| 场景 | 验收依据 |
| --- | --- |
| 设备回执重传 | 丢弃中心的确认后，以同一运行 ID 和事件序号重传。中心返回已有确认。迟到的旧轮次回执归入旧记录，当前轮次状态与设备确认一致。 |
| 任务输入回执 | 在运行中追加消息并交接多份文件。逐项核对待送达、已送达、已处理和待核对状态。完成或申请 Git 推送授权须覆盖本轮领取的输入，等待、请示和失败只确认回报的部分。重传应保留原处理时间和运行归属。 |
| Web 和 IM 并发回答 | 两端几乎同时回答同一请示。中心保存一个有效答案，并登记一次续接。设备离线时保留已答复状态，上线后以原生会话处理该输入。 |
| 断线与重启 | 模拟 daemon 在 CLI 仍运行或已退出时重启。通过本地执行记录核对进程归属，原进程继续受监控，已退出的运行补报证据。同一原生会话保持最多一个写入轮次。 |
| SSE 重连 | 使两个更新事务交错提交。客户端从上次游标重连后完整接收确认提交的事件，游标过期时重新取快照。 |
| 自动修复与独立 Review | 测试日志和启用时的 Review 都绑定待推候选 SHA。候选变化后重新验证，通过后推送并读回远端引用。 |
| 回执损坏和外部结果待核对 | CLI 写入文件后回执无法解析，保留文件和原回复，恢复时只补写回执。推送响应丢失时读取远端引用并据此登记结果。 |
